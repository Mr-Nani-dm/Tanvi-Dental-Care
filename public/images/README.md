# Tanvi image assets

The visual system expects these business-supplied assets:

- `tanvi-doctors.png` — the supplied authentic Tanvi doctor photograph.
- `tanvi-logo.png` — the supplied Tanvi Dental logo, unchanged.
- `tanvi-dental-emblem.png` — the supplied glossy 3D dental emblem.

Do not replace these with stock or AI-generated people. Do not alter the logo identity. Confirm patient/doctor image permissions before publication.

The current UI includes a graceful visual treatment when the doctor image is not yet present, so missing assets do not become broken-image UI.
