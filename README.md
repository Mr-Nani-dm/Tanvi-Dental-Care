# Tanvi Dental Care & Implant Centre

Frontend implementation workspace for the Tanvi Dental Care & Implant Centre website.

## Current status

Phase 12 implementation has started.

The repository was empty at initialization, so the first commit establishes the implementation guardrails before selecting a frontend framework or deployment architecture.

## Implementation principles

- Patient-intent-led architecture
- Mobile-first experience
- Professional enough to trust; warm enough to approach
- Verified business information only
- Clinical content requires appropriate medical review
- Phone / WhatsApp → Consultation is the primary conversion pathway
- Accessibility is mandatory
- Performance is a product requirement
- SEO pages must provide genuine patient value
- No invented services, credentials, reviews, pricing, statistics or medical claims
- The supplied Tanvi logo must be used without redesign or distortion

## Technical decisions intentionally not locked yet

- Frontend framework
- Rendering architecture
- CMS
- Hosting/deployment
- Form backend
- Analytics platform
- Maps provider
- Multilingual URL architecture

These must be explicitly decided before framework-specific production code is introduced.

## Next implementation step

Select and document the frontend technology decision, then establish the application shell, design tokens, reusable components and approved MVP routes.
